## The state of the product in five lines

- **17 of 17 routes** are on the designer UI. The migration is finished.
- **298 of 349 requirements** are implemented and evidenced. 17 are open.
- **None of the 17 can be closed by writing code today** — they need a design asset, a field
  definition from RD, or a product decision. The audit lists which is which.
- **There is no backend.** The API boundary is real and mocked (`src/lib/api/`); the balance,
  history and community content are local.
- **Credit pricing follows `specs/areas/11`** as of 2026-08-19 — per-second and tiered, computed
  at run time, not flat constants.
